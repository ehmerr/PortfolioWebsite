
# 💼 Portfolio Website

A personal portfolio website to showcase my skills, projects, and experience. Built with **React.js** and designed to be clean, responsive, and easy to navigate.

🔗 Live Demo: [portfolio-website-theta-seven-31.vercel.app](https://portfolio-website-theta-seven-31.vercel.app/)

---

# 🖼️ Features

- Responsive design for all screen sizes
- Sections: Home, About, Skills, Projects, Contact
- Smooth scroll and basic animations
- Easy to update content (projects, skills, etc.)

---

# 🛠️ Tech Stack

- Frontend: React.js, HTML, CSS, JavaScript
- Deployment: Vercel
- Version Control: Git, GitHub

---


# 🚀 Getting Started

1. Clone the repo
```bash
git clone https://github.com/your-username/portfolio-website.git
```

2. Install dependencies
```bash
cd portfolio-website
npm install
```

3. Run locally
```bash
npm start
```
